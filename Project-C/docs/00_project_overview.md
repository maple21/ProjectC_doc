# Project C Overview

## Genre
Extraction-based adventure survival game.

## Core Loop
Lyra leaves Capital, explores Outland, gathers resources, researches the environment, and returns before danger escalates.

## Core Concept
Capital is a safe underground base. Outland is a dangerous natural environment affected by disasters, magnetic field, poisonous fog, sandstorms, and hostile entities.

## Main Characters
| Name | Role |
|---|---|
| Lyra | Humanoid exploration unit |
| Pip | Weasel-like companion |
| Relay | Memory transmission system |

## Core Theme
Memory succession, survival, exploration limits.
